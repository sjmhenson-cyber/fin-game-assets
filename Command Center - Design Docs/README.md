# Command Center — Design Doc Set

Compiled from: the V4 handoff package, the unbuilt Gemini redesign proposal, and everything decided in design conversations since.

## Files
1. **01-core-loop.md** — the one-page loop, no implementation detail
2. **02-game-design-document.md** — the master doc: pillars, world, economy, combat, characters
3. **03-status-tracker.md** — built vs. planned, feature by feature
4. **04-open-questions.md** — unresolved design decisions, tracked so nothing gets lost

## How to use this with Claude
Start a build session, point Claude at `02-game-design-document.md` for full context, and `03-status-tracker.md` to know what's already done. Update the tracker as features ship. Add resolved items from `04-open-questions.md` into the GDD once decided, and delete them from that file.
