# Core Loop

```
        EARN                    ROUTE                     RESOLVE
  (real income event)     (assign by debt type)      (verb matches type)

   Payday / Business  ──▶   Combat debt        ──▶   Fight (Sapphire Lake)
   income arrives           (adversarial,             siege a monster,
        │                    interest-bearing)         HP = balance
        │                        │
        ▼                        ▼
   Audit? (optional,        Asset debt          ──▶   Build (The Keep of
   only if amount               (secured,               Ēkehya) upgrade
   looks off vs.                 IKEA-type)              house/appliances
   your usual)                   │
        │                        ▼
        ▼                   Small/interpersonal  ──▶   Deliver (courier
   Deposited to                  debt (Venmo-type)       errand, low stakes)
   player's Vault
                                                              │
                                                              ▼
                                                         REPEAT next
                                                         payday / turn
```

**The one rule everything answers to:** 1 gold = $1, always. Nothing in the
game can create or destroy money that isn't real.

**The one filter everything routes through:** debt type decides the verb.
Only adversarial, interest-bearing debt becomes a monster. Everything else
gets a non-combat resolution.
